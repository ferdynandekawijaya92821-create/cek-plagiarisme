1 · Impor file ekspor

Hampir semua aplikasi keuangan bisa mengekspor transaksi ke CSV atau Excel. Kolom tanggal, jumlah, kategori, dan akun dikenali otomatis.

Cara mengekspor dari aplikasi keuangan
  • Money Lover, Wallet, Monefy, Spendee, Money Manager, dll. — buka menu pengaturan/laporan, cari Ekspor / Export / Backup ke CSV atau Excel, lalu simpan atau kirim filenya ke perangkat ini.
  • Mobile/internet banking — unduh mutasi rekening dalam format CSV/Excel. Format jumlah dengan akhiran CR/DB atau kolom Debit/Kredit didukung.
  • Catatan sendiri di Excel/Google Sheets — cukup punya kolom Tanggal dan Jumlah (atau Pemasukan & Pengeluaran).
  • File berformat PDF belum bisa dibaca; pilih CSV/Excel saat mengekspor.

2 · Hubungkan tautan (sinkron otomatis)

Jika aplikasi Anda menyinkronkan data ke Google Sheets atau menyediakan tautan CSV, tempel tautannya. Data diambil ulang setiap aplikasi ini dibuka.

Syarat Google Sheets
  • Bagikan sheet: Bagikan → Siapa saja yang memiliki link → Pelihat, atau File → Bagikan → Publikasikan ke web (format CSV).
  • Tab yang dibaca adalah tab pada tautan (gid). Baris judul boleh ada di atas tabel.
