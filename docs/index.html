    Pengaturan pencocokan

    Bagian naskah dihitung sama bila sejumlah kata berurutan juga muncul di sumber. Semakin sensitif, semakin banyak frasa umum ikut terhitung.

    Opsi filter

    Opsi filter ikut dicantumkan di sampul laporan. Daftar pustaka dikenali dari judul seperti DAFTAR PUSTAKA, REFERENSI, atau REFERENCES.

    Pencarian Googleopsional · menjangkau seluruh web

    Isi API key Google Programmable Search milik Anda sendiri. Gratis 100 pencarian per hari. Kunci hanya disimpan di perangkat ini.

    1. Buka programmablesearchengine.google.com, buat mesin pencari baru, dan pilih "Search the entire web". Salin ID-nya (cx).
    2. Buka console.cloud.google.com, aktifkan Custom Search API, lalu buat API key.
    3. Tempel keduanya di atas, lalu centang "Google" di panel Cek di internet.

    Indeks kesamaan

    Naskah dipecah menjadi rangkaian kata berurutan (standar 5 kata). Rangkaian yang juga ada di sumber ditandai sama dan diberi warna serta nomor sesuai sumbernya.

    kesamaan = kata yang sama dengan sumber ÷ total kata

    Setiap kata hanya dihitung untuk satu sumber, sehingga persentase per sumber menjumlah ke total. "Topik" menunjukkan kemiripan kosakata, berguna untuk melihat parafrase ringan.

    Kemungkinan AI

    Dinilai dari gaya tulisan: keseragaman panjang kalimat, frasa klise khas AI, kata sambung di awal kalimat, keseragaman paragraf, pengulangan kata pembuka, dan keragaman kosakata. Gaya tidak baku menurunkan skor.

    0–35% cenderung manusia35–65% campuran65–100% cenderung AI

    Setiap sinyal punya bobot. Sinyal berbobot kecil hanya sedikit memengaruhi skor.

    Cek di internet

    Kalimat paling khas dicari di Wikipedia Indonesia dan Inggris, abstrak jurnal ilmiah OpenAlex, dan Google bila API key diisi. Halaman yang ditemukan diambil teksnya lalu dibandingkan.

    Tanpa Google, blog, situs berita, dan repositori kampus tidak terjangkau. Gunakan daftar "Periksa manual di Google" untuk itu.

    Privasi

    • Naskah dan berkas diproses di perangkat Anda. CekTeks tidak punya server dan tidak mengumpulkan data.
    • Saat Anda menekan "Cari", kata kunci dari beberapa kalimat dikirim ke mesin pencari yang Anda centang (Wikipedia, OpenAlex, Google).
    • Draf naskah, sumber, kunci API Google, dan pilihan tema disimpan di browser perangkat ini saja.

    Pakai offline

    Setelah situs dibuka sekali, CekTeks tetap berjalan tanpa internet, kecuali fitur Cek di internet. Pasang ke layar utama lewat menu browser agar terasa seperti aplikasi.

    File CekTeks.html berisi seluruh aplikasi. Simpan, lalu buka dengan browser kapan saja tanpa akun, langganan, atau internet.

    Format berkas

    PDF, Word (.docx, dan .doc lama secara terbatas), OpenDocument (.odt), PowerPoint (.pptx), RTF, HTML, Markdown, dan teks biasa.

    PDF hasil pindaian berupa gambar tidak berisi teks sehingga tidak bisa dibaca.

    Batasan

    • Deteksi AI adalah perkiraan. Tulisan manusia yang sangat formal bisa mendapat skor sedang.
    • CekTeks tidak memiliki basis data tugas dan jurnal tertutup seperti Turnitin.
    • Parafrase berat dan terjemahan sulit terdeteksi.
    • Teks di bawah 80 kata memberi hasil AI yang kurang andal.
    CekTeks · Analisis berjalan di perangkat Anda. Naskah tidak dikirim ke server.
