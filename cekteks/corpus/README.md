# Korpus pembanding

Letakkan dokumen referensi di folder ini (`.txt`, `.md`, `.docx`, `.pdf`, termasuk subfolder).
Semua berkas di sini otomatis dipakai sebagai sumber pembanding saat cek plagiarisme
(kecuali opsi "Gunakan korpus bawaan" dimatikan / `--no-corpus`).

Contoh: kumpulkan tugas angkatan sebelumnya, jurnal, atau artikel rujukan di sini.
Lokasi folder dapat diganti dengan variabel lingkungan `CEKTEKS_CORPUS`.
